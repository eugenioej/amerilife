1. What is ideaXchange?

ideaXchange is AmeriLife’s private member area on amerilife.com. Content is authored in WordPress and displayed on the gated site after users sign in with their AmeriLife Microsoft account.

As a content editor, you work entirely in WordPress Admin. You do not need to touch code or the public website theme. When you publish or update a post in WordPress, the live ideaXchange experience updates automatically.

Important: ideaXchange content is separate from the public Insights magazine (/insights/). Use the ideaXchange menus described in this guide — not the public Insights post type.

3. Site sections & who can see them

ideaXchange is organized into pillars (main sections). Which pillars a member can open depends on their login group (Brokerage or Career). This is controlled by IT / Entra — not by a field in WordPress.

ideaXchange section Brokerage users Career users
Home (main feed) ✓ ✓
Recruiting Hub ✓ ✓
Sales Leaderboard ✓ —
Career Leaderboard — ✓
Career Spotlight (carriers) ✓ ✓
Sales Success (incentives & stories) ✓ ✓
Two layers of “visibility”:
① Section access — which pillars appear in the nav (Brokerage vs Career login).
② Item visibility — set on each post in WordPress (see Section 4). Both must align for a user to see a specific piece of content.

4. Audience visibility (per item)

Almost every ideaXchange content type has an Audience visibility box in the WordPress editor (right sidebar). Use it to control which logged-in groups can see that specific item.

Setting in WordPress Who can see this item
Brokerage Brokerage (sales / distribution) users only
Career Career (recruiting) users only
Brokerage+Career Everyone with ideaXchange access (default)

Applies to: Articles, Case Studies, Companies, Carriers, and Leaderboard tables.

How to set visibility

1
Open the post in WordPress (Edit Article, Edit Case Study, etc.).
2
Find the Audience visibility panel on the right.
3
Choose Brokerage, Career, or Brokerage+Career.
4
Click Update or Publish.

The post list table also shows a Visibility column so you can audit content at a glance.

5. Articles — fields, tags & placement

ideaXchange Articles are the primary story format. They power the Home feed and appear in multiple pillars based on how you tag them.

Standard WordPress fields

  • Title — headline on cards and article page
  • Content — full article body
  • Excerpt — short summary on listing cards (recommended)
  • Featured image — thumbnail on feeds and hero layouts
  • Slug — URL-friendly name (auto-generated from title; edit if needed)

Topics (category-style)

Assign one ideaXchange Topic for the content theme. Default topics:

  • Health
  • Wealth
  • Leadership
  • Life

Topics appear as badges on article cards and in breadcrumbs.

Tags — controls which pillar section uses the article

Assign the correct ideaXchange Tag so the article surfaces in the right area:

Tag to assign Where the article appears
Sales Sales Leaderboard — newsroom / sidebar articles (brokerage users)
Recruit Recruiting Hub — articles column and related recruiting content
Initiative Sales Success — incentives, contests, and success stories
Featured Marks the article for Featured rows on feeds (see below)
Rule of thumb: If an article should live in Recruiting Hub, add the Recruit tag. For Sales Success content, add Initiative. For Sales Leaderboard sidebars, add Sales. Articles with no pillar tag still appear on the Home feed for users who pass visibility rules.

Featured & Spotlight placement

Control prominence on listing pages:

  • Featured — check Featured in Custom Fields or assign the Featured tag. Puts the article in the “Featured articles” row on Home and similar grids.
  • Spotlight — enable the Spotlight custom field (is_spotlight). Highlights the article in the sidebar “Spotlight” slot on feed-style pages.

Tip: In the block editor, open Preferences → Panels and enable Custom fields if you do not see Spotlight / Featured checkboxes.

Article workflow (step by step)

1
ideaXchange Articles → Add New
2
Enter title, excerpt, body, and featured image.
3
Pick a Topic and the correct Tag (Sales / Recruit / Initiative).
4
Set Audience visibility (Brokerage, Career, or both).
5
Optionally mark Featured or Spotlight.
6
Publish. Article appears on Home and tagged pillar sections.

7. Carriers (Career Spotlight)

ideaXchange Carriers power the Career Spotlight section (carrier partner profiles). Visible to both Brokerage and Career users.

Carrier profile fields

  • Title, excerpt, body, featured image (logo)
  • Brand color — hex code for accent styling (e.g. #244260)
  • Website URL
  • Hero tile — large tile in the top row of the carrier grid
  • Featured in additional grid — secondary featured placement
  • Highlights — repeater with icon + short label (e.g. competitive rates, technology)
  • Carrier resources — downloadable PDFs (Product Portfolio, Rate Sheets, Agent Resources, etc.)
  • Audience visibility

Use Choose file in the Media Library for each resource — do not paste attachment IDs manually.

8. Sales Leaderboard tables

The ideaXchange Leaderboard menu contains exactly seven pre-defined tables. You cannot add or delete tables — only update their data.

How to update rankings

1
Go to ideaXchange Leaderboard → Leaderboard tables (7).
2
Click the table you need to update (e.g. Health YTD, Wealth YTD).
3
Under Upload table data, choose an .xlsx file (recommended), .csv, or .json.
4
Set the Report date.
5
Click Update. The upload replaces all rows for that table.

Required columns: affiliate, ytd, lytd, vs_lytd, vs_lqtd, vs_lmtd, trend

Excel (.xlsx) is preferred because it preserves ▲ / ▼ trend symbols better than CSV.

9. Publishing checklist

Before publishing any ideaXchange item, confirm:

  • Correct content type (Article, Case Study, Company, Carrier, or Leaderboard table)
  • Title, excerpt, and featured image are complete
  • For articles: correct Topic and Tag (Sales / Recruit / Initiative)
  • Audience visibility matches the intended audience (Brokerage / Career / both)
  • Case studies: Company linked and campaign downloads attached
  • Carriers: highlights and resource files uploaded
  • Leaderboard: data file uploaded and report date set
  • Status is Published (not Draft)
