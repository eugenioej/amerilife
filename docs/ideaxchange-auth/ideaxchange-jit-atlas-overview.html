IdeaXchange SSO — JIT Overview

AmeriLife · amerilife.com · Technical reference for the IT team

IdeaXchange uses a headless architecture: the public site at amerilife.com (Next.js), content in WordPress, and login via Microsoft Entra ID. With Just-in-Time (JIT) provisioning, members sign in with Microsoft and access is created on first login — no SCIM sync into WordPress and no auth plugins.

2. JIT login flow

sequenceDiagram
    participant U as User
    participant S as amerilife.com
    participant E as Microsoft Entra
    participant W as WordPress CMS

    U->>S: Open /ideaxchange/
    U->>S: Sign in with Microsoft
    S->>E: OAuth login
    E->>S: User identity + groups
    Note over S: JIT - access created on first login
    S->>W: Fetch content via GraphQL
    W->>S: Content data
    S->>U: Personalized IdeaXchange experience
Summary: Entra runs login. The frontend enforces access. WordPress holds content. Members never log into WordPress. Access is managed via Entra groups.
